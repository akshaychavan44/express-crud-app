This project is a full-stack web application designed to perform CRUD (Create, Read, Update, Delete) operations on notes. 
Users can create notes with a title and content, view all notes in a structured layout, edit existing notes, delete notes, and search notes by keyword. 
The system follows a client-server architecture where the frontend communicates with the backend through REST APIs.

FrontEnd: HTML5, CSS3, JavaScript, Express.js, Node.js
BackEnd : java, Spring Boot framework, Spring data MongoDB
