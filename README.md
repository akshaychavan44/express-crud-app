# Notes Management System

A Notes Management System built using Java, Spring Boot, MongoDB, JavaScript, HTML, and CSS. The application allows users to create, view, update, and delete notes. REST APIs were tested using Postman.

## Tech Stack

- Java
- Spring Boot
- MongoDB
- JavaScript
- HTML
- CSS
- Postman

## Features

- Create notes
- View all notes
- Update notes
- Delete notes
- REST API testing using Postman

## How to Run

1. Start MongoDB locally.
2. Open the Spring Boot project in STS or your preferred IDE.
3. Run the Spring Boot application.
4. Open the frontend HTML file in the browser.
5. Test APIs using Postman.

## Additional Project

This repository also contains a basic CRUD REST API project built using Node.js and Express.js.

### Tech Stack

- Node.js
- Express.js
- Postman

### Features

- Create notes
- Update notes
- Delete notes
- Backend-only REST API
- API testing using Postman

## Project Description

Developed a Notes Management System using Java, Spring Boot, MongoDB, JavaScript, HTML, and CSS, where users can create, view, update, and delete notes. Also included a backend-only CRUD REST API project using Node.js and Express.js for basic note management operations.
